DEUDA PENDIENTE

Cómo abrir el juego

Antes de empezar

"Deuda Pendiente" está hecho en Java, por eso no se instala como un programa común: se abre como proyecto desde un editor de código y se ejecuta desde ahí. Para seguir estos pasos tenés que haber descargado el juego desde el menú principal. El archivo se llama DeudaPendiente.zip y se guarda en la carpeta de descargas de tu computadora.

Programas necesarios

Instalalos una sola vez, en este orden:

  1. JDK (Java Development Kit). Es lo que permite ejecutar Java. Se recomienda la versión 17 o una más nueva. Descargalo desde adoptium.net y seguí el instalador.
  2. Visual Studio Code. Es el editor donde se abre el juego. Descargalo desde code.visualstudio.com.
  3. Extension Pack for Java. Dentro de VS Code, abrí el panel de extensiones (Ctrl + Shift + X), buscá Extension Pack for Java (de Microsoft) y presioná "Instalar".

Pasos para abrir el juego

  1. Buscá el archivo descargado. Abrí la carpeta "Descargas" y ubicá DeudaPendiente.zip.
  2. Extraé el contenido. Hacé clic derecho sobre el archivo y elegí "Extraer todo...". Después elegí una carpeta y presioná "Extraer". No abras el proyecto desde dentro del .zip: tiene que estar extraído.
  3. Abrí Visual Studio Code.
  4. Abrí la carpeta del juego. En el menú superior elegí Archivo > Abrir carpeta..., seleccioná la carpeta que extrajiste y presioná "Seleccionar carpeta". Si VS Code pregunta si confiás en los autores, elegí "Sí, confío".
  5. Esperá a que cargue Java. La primera vez puede tardar un momento. Cuando termine, en la barra de abajo vas a ver el ícono de Java listo (sin el símbolo de carga).
  6. Abrí el archivo principal. En el panel de la izquierda (Explorador), buscá y abrí el archivo .java que contiene el método main. Ese es el archivo que inicia el juego.
  7. Ejecutá el juego. Presioná el botón ▶ Run que aparece arriba a la derecha del editor, o el texto "Run" que aparece sobre el método main. También podés usar Ctrl + F5.
  8. Jugá. Se abre el juego en una ventana nueva y vas a ver la pantalla principal.

Menú del juego

  • Comenzar: inicia una partida nueva. Primero ingresás tu nombre y elegís tu género.
  • Cargar partida: continúa una partida guardada.
  • Ajustes: cambia la velocidad del texto y el modo de pantalla (ventana o pantalla completa).
  • Salir: cierra el juego.

Recordá guardar tu partida antes de salir para no perder el progreso.

Si algo no funciona

  • No aparece el botón Run: verificá que instalaste Extension Pack for Java y esperá a que termine de cargar. Si sigue sin aparecer, cerrá y volvé a abrir VS Code.
  • Dice que no encuentra Java o el JDK: instalá el JDK y reiniciá VS Code.
  • Error de versión de Java: instalá un JDK más nuevo (17 o superior).
  • Aparecen errores en rojo al abrir la carpeta: asegurate de haber abierto la carpeta correcta, la que contiene todo el proyecto, y que esté extraída del .zip.
  • La descarga no terminó bien: volvé a descargar el juego desde el menú principal.
  • El juego no carga: cerralo y volvé a ejecutarlo desde VS Code.
